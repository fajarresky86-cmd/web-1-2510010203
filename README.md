## Fitur Utama (Modul 1 – Modul 4)

1. Struktur Semantik & Aksesibilitas (Modul 1): Tata letak menggunakan elemen HTML5 semantik (`header`, `nav`, `main`, `section`, `article`, `table`, `footer`) dengan atribut ARIA untuk aksesibilitas pembaca layar.
2. Pencarian, Filter Kategori & Validasi Formulir (Modul 3):Pencarian produk secara langsung (*real-time search*), penyaringan berdasarkan kategori (Semua, Kain, Pakaian, Aksesoris), serta validasi formulir interaktif di JavaScript.
4. Integrasi Data JSON & API Publik Asinkron (Modul 4):
   * Pemuatan 12 data produk secara asinkron dari `data/katalog.json` menggunakan `fetch()` dan `async/await`.
   * Widget **Jadwal Salat Kota Banjarmasin** (`ID_KOTA = 2113`) secara *real-time* dari API MyQuran v2 (`https://api.myquran.com`).
